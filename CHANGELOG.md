# Changelog

Automated Nightly and Stable notes now live in
[GitHub Releases](https://github.com/chricarp/lictory/releases), generated from
reviewed PR metadata. Do not prepare versions or edit this file for new releases.

User-facing changes are collected here before a release. Lictory uses
[Semantic Versioning](https://semver.org/): major versions for breaking changes,
minor versions for features, and patches for fixes. Hotfixes are patch releases.
