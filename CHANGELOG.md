# Changelog

Release notes for every Nightly and Stable version live in
[GitHub Releases](https://github.com/chricarp/lictory/releases), generated from
reviewed PR metadata. Do not prepare versions or edit this file for new releases.

Lictory uses [Semantic Versioning](https://semver.org/); see
[versions and releases](docs/operations/releases.md) for how PR titles determine
the version.
