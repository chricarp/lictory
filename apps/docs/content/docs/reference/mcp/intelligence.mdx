### `draftProposals`

**Draft proposals from rough material.** Query (read tokens too) · talks to an outside system

Lictory Intelligence reads rough material (meeting notes, customer requests, support tickets, documents) and returns _proposed_ proposals for one project: title, problem, expected outcome, open questions, suggested reviewer disciplines and related recorded decisions or approved specifications. Every draft cites verbatim excerpts of the sources and lists what was inferred rather than stated; citations, disciplines and references the server could not verify are removed and counted in `filtered`. Nothing is created. Show the drafts to the person and create only the ones they choose, with createWorkItem (a specification-backed type, the draft's title and its `description`), adjusting them as they ask. Requires Lictory Intelligence to be enabled and permission to edit specifications in the project. The material is sent to the AI provider and not stored.

| Field            | Type           | Required | Description                                                                                                      |
| ---------------- | -------------- | -------- | ---------------------------------------------------------------------------------------------------------------- |
| `organizationId` | string         | Yes      | Exact organization id or slug from listOrganizations.                                                            |
| `projectId`      | string         | Yes      | Project the proposals are for.                                                                                   |
| `sources`        | list of object | Yes      | Up to 10 pieces of material. At most 60,000 characters are analysed in total; the rest is reported as truncated. |
