Reviews, proposals and context of Lictory Intelligence. Every tool takes `organizationId` (an id or slug from `listOrganizations`) unless it says otherwise. See the [overview](/reference/mcp) for errors, retries and what agents may not do.

### `setAiPolicy`

**Set Lictory Intelligence policy.** Command · retry key `mutationId` · **a person's decision**: refused to agents (the person decides in Organization settings → Intelligence)

Administrators: allow or forbid sending this organization's content to the AI provider.

| Field            | Type    | Required | Description                                                                                |
| ---------------- | ------- | -------- | ------------------------------------------------------------------------------------------ |
| `organizationId` | string  | Yes      | Exact organization id or slug from listOrganizations.                                      |
| `mutationId`     | id      |          | Idempotency key. Retrying with the same value never applies the command twice.             |
| `enabled`        | boolean | Yes      | true lets Lictory Intelligence send content to the configured AI provider; false stops it. |

```json title="setAiPolicy arguments"
{
  "organizationId": "acme",
  "mutationId": "6f1d2c3b-8a9e-4f70-b1c2-d3e4f5a6b7c8",
  "enabled": true
}
```

| Field            | Type   | Required | Description                                                                                                             |

| `title`          | string | Yes      | Entry title.                                                                                                            |
| `content`        | string |          | Markdown note content.                                                                                                  |
| `file`           | object |          | A document (PDF, Word, Markdown, text…) converted to Markdown on the server. Replaces `content`.                        |

}

### `draftProposals`

**Draft proposals from rough material.** Query (read tokens too) · talks to an outside system

Lictory Intelligence reads rough material (meeting notes, customer requests, support tickets, documents) and returns _proposed_ proposals for one project: title, problem, expected outcome, open questions, suggested reviewer disciplines and related recorded decisions or approved specifications. Every draft cites verbatim excerpts of the sources and lists what was inferred rather than stated; citations, disciplines and references the server could not verify are removed and counted in `filtered`. Nothing is created. Show the drafts to the person and create only the ones they choose, with [createWorkItem](/reference/mcp/work-items#createworkitem) (a specification-backed type, the draft's title and its `description`), adjusting them as they ask. Requires Lictory Intelligence to be enabled and permission to edit specifications in the project. The material is sent to the AI provider and not stored.

| Field            | Type           | Required | Description                                                                                                      |
| ---------------- | -------------- | -------- | ---------------------------------------------------------------------------------------------------------------- |
| `organizationId` | string         | Yes      | Exact organization id or slug from listOrganizations.                                                            |
| `projectId`      | string         | Yes      | Project the proposals are for.                                                                                   |
| `sources`        | list of object | Yes      | Up to 10 pieces of material. At most 60,000 characters are analysed in total; the rest is reported as truncated. |

```json title="draftProposals arguments"
{
  "organizationId": "acme",
  "projectId": "3b0f6c1e-5d2a-4e8b-9f61-2a7c4d9e8b10",
  "sources": [
    {
      "label": "Customer call, 2 Nov",
      "text": "Refunds that time out are never retried; support retries them by hand."
    }
  ]
}
```
