Repositories, branches, pull requests, checks and issues mirrored from GitHub, GitLab or Bitbucket. Every tool takes `organizationId` (an id or slug from `listOrganizations`) unless it says otherwise. See the [overview](/reference/mcp) for errors, retries and what agents may not do.

### `disconnectCodeHost`

**Disconnect a code host.** Command · no retry key: read before repeating · destructive

Organization administrators: remove a code host connection. Its repositories, pull requests and links stay as history and return when the same host and account are connected again; writes not yet sent are canceled.

| Field            | Type   | Required | Description                                           |
| ---------------- | ------ | -------- | ----------------------------------------------------- |
| `organizationId` | string | Yes      | Exact organization id or slug from listOrganizations. |
| `connectionId`   | string | Yes      | Code host connection id (from listCodeRepositories).  |

```json title="disconnectCodeHost arguments"
{
  "organizationId": "acme",
  "connectionId": "101d6e1e-aa2d-4eda-af1a-59cba1afb49b"
}
```

### `linkCodeRepository`

**Link a repository to a project.** Command · safe to repeat · talks to an outside system

Project administrators: make a repository serve a project. Lictory then mirrors its pull requests, issues, checks and the branches and commits that name the project's work item keys (PAY-142), and backfills the last 30 days. `repository` is the full name (owner/name, group/project) or the host's id.

| Field            | Type   | Required | Description                                                                                         |

| `repository`     | string | Yes      | The repository's full name (owner/name, group/project) or the host's id (listCodeHostRepositories). |
| `projectId`      | string | Yes      | Project id (from getWorkspace).                                                                     |

### `mergeCodePullRequest`

**Merge a pull request.** Command · retry key `mutationId` · talks to an outside system · **a person's decision**: refused to agents (the person decides in Code → the pull request → Merge (or Autopilot, when the project's autonomy policy merges passing agent pull requests))

Merge a pull request on its code host, only when the person explicitly asked to. `expectedHeadSha` is the head commit the person reviewed: the merge is refused if new commits arrived. Lictory also refuses a draft, failing or running checks, requested changes (on the host or in a review recorded in Lictory), conflicts, and a head the host reported no checks for when the work it delivers requires CI in its Definition of Done ([getCodePullRequest](/reference/mcp/code#getcodepullrequest) lists them as mergeBlockers); the host's branch protection applies on top. Merge while the code pull request is open (it becomes merged). Needs “Change properties” in a project the repository serves.

| `expectedHeadSha` | string                            | Yes      | The head commit SHA the person reviewed; refused if new commits arrived.                                     |

### `reviewCodePullRequest`

**Review a pull request.** Command · retry key `mutationId` · talks to an outside system

Record your review of a pull request's head commit in Lictory: `approve` or `request_changes`, with a body saying what you checked. The review belongs to that commit: new commits need a new review, and `expectedHeadSha` (the head you read) refuses the review if it moved. The project's Definition of Done counts the reviewer agent's approval of the head (or any approval when the policy names no reviewer agent). A comment on the host shows the verdict, signed. An agent never reviews its own pull request. Review while the code pull request is open. Needs “Change properties” in a project the repository serves.

### `setCodeHostLogin`

**Set your code host login.** Command · safe to repeat

Tell Lictory your login on a code host, so “mine” and “review requested” filters find your pull requests. It grants nothing. An empty login removes it.

| Field            | Type           | Required | Description                                             |
| ---------------- | -------------- | -------- | ------------------------------------------------------- |
| `organizationId` | string         | Yes      | Exact organization id or slug from listOrganizations.   |
| `connectionId`   | string         | Yes      | Code host connection id (from listCodeRepositories).    |
| `login`          | string or null | Yes      | Your login on that code host; empty or null removes it. |
