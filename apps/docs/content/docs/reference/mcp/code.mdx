Repositories, branches, pull requests, checks and issues mirrored from GitHub, GitLab or Bitbucket. Every tool takes `organizationId` (an id or slug from `listOrganizations`) unless it says otherwise. See the [overview](/reference/mcp) for errors, retries and what agents may not do.

### `disconnectCodeHost`

**Disconnect a code host.** Command · no retry key: read before repeating · destructive

Organization administrators: remove a code host connection. Its repositories, pull requests and links stay as history and return when the same host and account are connected again; writes not yet sent are canceled.

### `mergeCodePullRequest`

**Merge a pull request.** Command · retry key `mutationId` · talks to an outside system · **a person's decision**: refused to agents (the person decides in Code → the pull request → Merge (or Autopilot, when the project's autonomy policy merges passing agent pull requests))

Merge a pull request on its code host, only when the person explicitly asked to. `expectedHeadSha` is the head commit the person reviewed: the merge is refused if new commits arrived. Lictory also refuses a draft, failing or running checks, requested changes and conflicts (getCodePullRequest lists them as mergeBlockers); the host's branch protection applies on top. Merge while the code pull request is open (it becomes merged). Needs “Change properties” in a project the repository serves.

### `reviewCodePullRequest`

**Review a pull request.** Command · retry key `mutationId` · talks to an outside system

Record your review of a pull request's head commit in Lictory: `approve` or `request_changes`, with a body saying what you checked. The review belongs to that commit: new commits need a new review, and `expectedHeadSha` (the head you read) refuses the review if it moved. The project's Definition of Done counts the reviewer agent's approval of the head (or any approval when the policy names no reviewer agent). A comment on the host shows the verdict, signed. An agent never reviews its own pull request. Review while the code pull request is open. Needs “Change properties” in a project the repository serves.
