Work items, specifications and their revisions, branches, pull requests, reviews, discussions and suggestions. Every tool takes `organizationId` (an id or slug from `listOrganizations`) unless it says otherwise. See the [overview](/reference/mcp) for errors, retries and what agents may not do.

### `listWorkItems`

**List work items.** Query (read tokens too)

List work item summaries with review, readiness, child counts and lifecycle stage. Filter by project, team, type, local status/assignee, refinement state, lifecycle stage or title/key. lifecycle=ready means ready for delivery (checks pass) and excludes accepted, active and completed work, active delivery and completed work. External delivery facts come from the provider link; use lifecycle for cross-mode progress.

| ----------------- | ------------------------------------------------------------------------------------------------------------- | -------- | ---------------------------------------------------------------------------------------------------------------- |
| `organizationId`  | string                                                                                                        | Yes      | Exact organization id or slug from listOrganizations.                                                            |
| `projectId`       | string                                                                                                        |          | Project id (from getWorkspace).                                                                                  |
| `teamId`          | string                                                                                                        |          | Team id (from getWorkspace).                                                                                     |
| `typeId`          | string                                                                                                        |          | Work item type id (from getWorkspace).                                                                           |
| `statusId`        | string                                                                                                        |          | Workflow status id (from getWorkspace).                                                                          |
| `assigneeId`      | string or null                                                                                                |          | A member id, or null for unassigned items.                                                                       |
| `parentId`        | string                                                                                                        |          | Only direct children of this work item.                                                                          |
| `iterationId`     | string                                                                                                        |          | Iteration id (from getWorkspace).                                                                                |
| `refinementState` | `"draft"`, `"refinement"`, `"in_review"`, `"ready"`                                                           |          | Only items in this refinement state.                                                                             |
| `lifecycle`       | `"proposal"`, `"refinement"`, `"review"`, `"ready"`, `"committed"`, `"underway"`, `"completed"`, `"canceled"` |          | Only items at this lifecycle stage, across delivery modes; ready means checks pass and delivery has not started. |

### `createWorkItem`

**Create work item.** Command · retry key `mutationId`

Create a work item (Epic, Story, Task, Bug, Subtask or a custom type enabled in the project). Spec-backed types require edit-specifications; plain types require edit-specifications or change-properties in the project. `teamId` is optional. `typeId` and `teamId` come from [getWorkspace](/reference/mcp/organization#getworkspace); `description` is Markdown and becomes the first revision. Unknown fields are rejected. Specification text belongs in `description`, not `content`. Set an estimate afterwards with [updateWorkItem](/reference/mcp/work-items#updateworkitem). `source` \{ pageId, commitId, blockId?, quote? \} records committed page content the item is created from (you must be able to read the page; the commit must be one of its versions, the block one of that version's top-level blocks, the quote at most 2000 characters); only readers of the page see it. The result includes `key` and `revisionId`.

| Field            | Type           | Required | Description                                                                                                        |
| ---------------- | -------------- | -------- | ------------------------------------------------------------------------------------------------------------------ |
| `organizationId` | string         | Yes      | Exact organization id or slug from listOrganizations.                                                              |
| `mutationId`     | id             |          | Idempotency key. Retrying with the same value never applies the command twice.                                     |
| `projectId`      | string         | Yes      | Project id (from getWorkspace).                                                                                    |
| `workItemId`     | id             |          | Identifier for the new entity. Omit to have one assigned.                                                          |
| `typeId`         | string         | Yes      | Work item type id (from getWorkspace).                                                                             |
| `teamId`         | string or null |          | Team id (from getWorkspace).                                                                                       |
| `parentId`       | string or null | Yes      | Parent work item id or null for none; the parent's type level must be above this type's.                           |
| `title`          | string         | Yes      | Work item title.                                                                                                   |
| `description`    | string         |          | Specification or description, in Markdown.                                                                         |
| `statusId`       | string         |          | Workflow status id (from getWorkspace).                                                                            |
| `iterationId`    | string or null |          | Iteration id (from getWorkspace).                                                                                  |
| `assigneeId`     | string or null |          | User id of the person to assign (from searchMembers); null unassigns.                                              |
| `source`         | object         |          | The committed page content the item is created from, \{ pageId, commitId, blockId?, quote? \}, kept with the item. |
