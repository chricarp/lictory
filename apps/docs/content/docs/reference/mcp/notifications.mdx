The inbox, watching and notification preferences. Every tool takes `organizationId` (an id or slug from `listOrganizations`) unless it says otherwise. See the [overview](/reference/mcp) for errors, retries and what agents may not do.

### `listNotifications`

**List notifications.** Query (read tokens too)

Your inbox: review requests, blocking comments, mentions, approvals invalidated and similar events, newest first. Page with `before` set to the last item's `${createdAt}|${id}`.

| Field            | Type                              | Required | Description                                                                        |
| ---------------- | --------------------------------- | -------- | ---------------------------------------------------------------------------------- |
| `organizationId` | string                            |          | Exact organization id or slug from listOrganizations.                              |
| `projectId`      | string                            |          | Project id (from getWorkspace).                                                    |
| `teamId`         | string                            |          | Team id (from getWorkspace).                                                       |
| `kinds`          | list of string                    |          | Only notifications of these kinds.                                                 |
| `status`         | `"unread"`, `"all"`, `"archived"` |          | unread, all (default, not archived) or archived.                                   |
| `before`         | string                            |          | Page cursor: the last notification's `${createdAt}\|${id}` from the previous page. |
| `limit`          | integer                           |          | Most results to return.                                                            |

### `setNotificationPreferences`

**Set notification preferences.** Command · safe to repeat

Set in-app/email delivery per notification kind for an organization, project or team scope; `reset: true` removes a rule.

| Field            | Type                                    | Required | Description                                                                                                    |
| ---------------- | --------------------------------------- | -------- | -------------------------------------------------------------------------------------------------------------- |
| `organizationId` | string                                  | Yes      | Exact organization id or slug from listOrganizations.                                                          |
| `scope`          | `"organization"`, `"project"`, `"team"` | Yes      | Where the rules apply: organization, project or team.                                                          |
| `scopeId`        | string                                  | Yes      | The organization (id or slug), project or team id the scope names.                                             |
| `rules`          | list of object                          | Yes      | Per notification kind: \{ kind, inApp, email \}, or \{ kind, reset: true \} to fall back to the broader scope. |

```json title="setNotificationPreferences arguments"
{
  "organizationId": "acme",
  "scope": "organization",
  "scopeId": "d4c30c78-4918-43d7-a56b-e5d54501a511",
  "rules": [
    {
      "kind": "review_requested",
      "inApp": true,
      "email": false
    }
  ]
}
```

### `watchWorkItem`

**Watch work item.** Command · safe to repeat

Watch (true) or unwatch (false) a work item; null returns to following involvement.

| Field            | Type            | Required | Description                                                                |
| ---------------- | --------------- | -------- | -------------------------------------------------------------------------- |
| `organizationId` | string          | Yes      | Exact organization id or slug from listOrganizations.                      |
| `workItemId`     | string          | Yes      | Work item id, or its key such as PAY-142 (listWorkItems shows both).       |
| `watching`       | boolean or null | Yes      | true watches, false unwatches; null returns to following your involvement. |

```json title="watchWorkItem arguments"
{
  "organizationId": "acme",
  "workItemId": "PAY-142",
  "watching": true
}
```
