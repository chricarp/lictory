Linked Slack channels. Every tool takes `organizationId` (an id or slug from `listOrganizations`) unless it says otherwise. See the [overview](/reference/mcp) for errors, retries and what agents may not do.

### `getSlackConnection`

**Slack connection.** Query (read tokens too)

Whether the organization is connected to a Slack workspace (`status`: none, pending, connected, invalid, disconnected), which workspace, the last error and how many channels are linked. Organization administrators also get the Slack app manifest for this installation and its URLs.

| Field            | Type   | Required | Description                                           |
| ---------------- | ------ | -------- | ----------------------------------------------------- |
| `organizationId` | string | Yes      | Exact organization id or slug from listOrganizations. |

```json title="getSlackConnection arguments"
{
  "organizationId": "acme"
}
```

### `listSlackChannels`

**List Slack channels.** Query (read tokens too) · talks to an outside system

Slack channels the Lictory app has been invited to, with whether each is already linked to a Lictory channel. Invite the app in Slack (/invite @Lictory) to see a channel here.

| Field            | Type   | Required | Description                                           |
| ---------------- | ------ | -------- | ----------------------------------------------------- |
| `organizationId` | string | Yes      | Exact organization id or slug from listOrganizations. |

```json title="listSlackChannels arguments"
{
  "organizationId": "acme"
}
```

### `linkSlackChannel`

**Link channel to Slack.** Command · safe to repeat · talks to an outside system · **a person's decision**: refused to agents (the person decides in The channel's header → Link to a Slack channel)

Link a Lictory channel you manage (public or private, not direct) to a Slack channel the Lictory app is in (`slackChannelId` from [listSlackChannels](/reference/mcp/slack#listslackchannels)): from then on both sides see the same conversation. Public channels link to public Slack channels and private ones to private ones. `backfill` imports up to 200 of the Slack channel's latest messages once. Messages stay owned by the side they were written on. Linking shares the conversation with Slack: only call this when the person explicitly asked.

| Field            | Type    | Required | Description                                                     |
| ---------------- | ------- | -------- | --------------------------------------------------------------- |
| `organizationId` | string  | Yes      | Exact organization id or slug from listOrganizations.           |
| `channelId`      | string  | Yes      | Channel id (from listChannels).                                 |
| `slackChannelId` | string  | Yes      | The Slack channel's id (listSlackChannels), such as C0123ABCD.  |
| `backfill`       | integer |          | How many of the Slack channel's latest messages to import once. |

```json title="linkSlackChannel arguments"
{
  "organizationId": "acme",
  "channelId": "e6112029-cec1-4397-abe7-ccaae2ee924e",
  "slackChannelId": "3bcbb262-7d98-46fb-ace7-ac35d90e9dab"
}
```

### `unlinkSlackChannel`

**Unlink channel from Slack.** Command · safe to repeat

Stop syncing a Lictory channel with its Slack channel. Both keep their history; nothing more is sent either way.

| Field            | Type   | Required | Description                                           |
| ---------------- | ------ | -------- | ----------------------------------------------------- |
| `organizationId` | string | Yes      | Exact organization id or slug from listOrganizations. |
| `channelId`      | string | Yes      | Channel id (from listChannels).                       |

```json title="unlinkSlackChannel arguments"
{
  "organizationId": "acme",
  "channelId": "e6112029-cec1-4397-abe7-ccaae2ee924e"
}
```

### `retrySlackMessage`

**Retry sending to Slack.** Command · safe to repeat

Send again a message of a linked channel that could not reach Slack (your own, or any when you manage the channel).

| Field            | Type   | Required | Description                                           |
| ---------------- | ------ | -------- | ----------------------------------------------------- |
| `organizationId` | string | Yes      | Exact organization id or slug from listOrganizations. |
| `channelId`      | string | Yes      | Channel id (from listChannels).                       |
| `messageId`      | string | Yes      | Message id (from readChannel or readChannelThread).   |

```json title="retrySlackMessage arguments"
{
  "organizationId": "acme",
  "channelId": "e6112029-cec1-4397-abe7-ccaae2ee924e",
  "messageId": "ae2bea39-b23d-4c35-a1aa-f3f821c61382"
}
```
