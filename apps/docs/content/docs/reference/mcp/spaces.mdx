### `createSpace`

**Create space.** Command · retry key `mutationId`

Create a space of nested knowledge pages. `slug` is its lowercase URL handle, unique among active spaces. `home` is \{\} (the organization), \{ projectId \} or \{ projectId, teamId \}. `accessMode` inherited (default: the home's members edit, every organization member views, named grants add) or restricted (only named grants; the creator receives edit). `publishing` direct (default: editors publish main's live draft) or reviewed (changes to main need reviewed pull requests).

| Field            | Type                          | Required | Description                                                                                                                                       |
| ---------------- | ----------------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `organizationId` | string                        | Yes      | Exact organization id or slug from listOrganizations.                                                                                             |
| `mutationId`     | id                            |          | Idempotency key. Retrying with the same value never applies the command twice.                                                                    |
| `spaceId`        | id                            |          | Identifier for the new entity. Omit to have one assigned.                                                                                         |
| `name`           | string                        | Yes      | Space name shown to people.                                                                                                                       |
| `slug`           | string                        | Yes      | Short address of the space, unique in the organization, such as payments-handbook.                                                                |
| `description`    | string                        |          | What the space is for.                                                                                                                            |
| `icon`           | string                        |          | An emoji or short symbol shown with the name.                                                                                                     |
| `home`           | object                        |          | Where the space lives: \{\} the organization, \{ projectId \} a project, \{ projectId, teamId \} a team. Members of the home can edit by default. |
| `accessMode`     | `"inherited"`, `"restricted"` |          | inherited: the home's members can read and edit; restricted: only people named with setSpaceGrant.                                                |
| `publishing`     | `"direct"`, `"reviewed"`      |          | direct: editors publish changes themselves; reviewed: changes to main go through a pull request.                                                  |

```json title="createSpace arguments"
{
  "organizationId": "acme",
  "mutationId": "6f1d2c3b-8a9e-4f70-b1c2-d3e4f5a6b7c8",
  "name": "payments",
  "slug": "slug"
}
```

### `createPageThread`

### `commitDraft`

**Commit page draft.** Command · retry key `mutationId` · **a person's decision**: refused to agents (the person decides in The page in Spaces → Publish or Commit)

Seal the live draft of a page line (`branchId`, its `draftId` and `epoch`) at exactly `expectedSequence`, the stored sequence the editor last saw, into an immutable commit with an optional `message`. The commit's title is the draft's working title at that cut; `title` applies only when the draft has no working title of its own. Later edits stay uncommitted. On main in a Direct space this publishes the page. Allowed for editors of the space; a named branch only for its author and collaborators; main in a Reviewed space is protected (use [proposePageChange](/reference/mcp/spaces#proposepagechange) or a branch and pull request). Edits that cancel out record the cut without a commit (`nothingToCommit`). Agents cannot type into live drafts; they propose changes with [proposePageChange](/reference/mcp/spaces#proposepagechange).

| Field              | Type    | Required | Description                                                                                 |
| ------------------ | ------- | -------- | ------------------------------------------------------------------------------------------- |
| `organizationId`   | string  | Yes      | Exact organization id or slug from listOrganizations.                                       |
| `mutationId`       | id      |          | Idempotency key. Retrying with the same value never applies the command twice.              |
| `pageId`           | string  | Yes      | Page id (from listPages).                                                                   |
| `branchId`         | string  | Yes      | Page branch id (returned by createPageBranch).                                              |
| `draftId`          | string  | Yes      | Live draft id (returned when the draft was opened).                                         |
| `epoch`            | integer | Yes      | The draft's epoch you edited (returned with the draft); a new epoch means it was restarted. |
| `expectedSequence` | integer | Yes      | The draft's stored sequence you last saw; the commit seals exactly that cut.                |
| `title`            | string  | Yes      | Title of the commit, used only when the draft has no working title of its own.              |
| `message`          | string  |          | What changed, for the page's history.                                                       |

```json title="commitDraft arguments"
{
  "organizationId": "acme",
  "mutationId": "6f1d2c3b-8a9e-4f70-b1c2-d3e4f5a6b7c8",
  "pageId": "c5dd13a6-a268-4e92-ad1a-d7cdef812de5",
  "branchId": "9afcbf86-367d-402a-a44d-394652ce9df6",
  "draftId": "d841f386-efe0-4bd7-a508-f63c81bae380",
  "epoch": 1,
  "expectedSequence": 0,
```
