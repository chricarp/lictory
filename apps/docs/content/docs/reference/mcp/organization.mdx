Organizations, attachments, branding and what stays with people. Every tool takes `organizationId` (an id or slug from `listOrganizations`) unless it says otherwise. See the [overview](/reference/mcp) for errors, retries and what agents may not do.

### `listOrganizations`

**List organizations.** Query (read tokens too)

Organizations you belong to, with your application role (admin or member). An organization owner is reported as admin. Start here to find an organizationId.

No fields.

```json title="listOrganizations arguments"
{}
```

### `getWorkspace`

**Get workspace configuration.** Query (read tokens too)

The organization's projects (with their delivery settings, workflow statuses, enabled types, members, disciplines, teams and iterations), work item types, delivery targets and Lictory Intelligence policy, plus your application role and your capabilities in each project. Pass `projectId` to limit projects, statuses, teams, iterations, disciplines and delivery targets to that project. Organization roles are admin or member. Use it to resolve ids for other tools.

| Field            | Type   | Required | Description                                                                         |
| ---------------- | ------ | -------- | ----------------------------------------------------------------------------------- |
| `organizationId` | string | Yes      | Exact organization id or slug from listOrganizations.                               |
| `projectId`      | string |          | When set, the workspace is limited to this project. A missing project is not found. |

```json title="getWorkspace arguments"
{
  "organizationId": "acme"
}
```

### `listAttachments`

**List attachments.** Query (read tokens too)

Files attached to a work item (workItemId), to a page (pageId; readers of its space) or in a channel (channelId; readers of the channel).

| Field            | Type   | Required | Description                                                                 |
| ---------------- | ------ | -------- | --------------------------------------------------------------------------- |
| `organizationId` | string | Yes      | Exact organization id or slug from listOrganizations.                       |
| `workItemId`     | string |          | The work item the file belongs to.                                          |
| `pageId`         | string |          | The Lictory Spaces page the file belongs to (instead of workItemId).        |
| `channelId`      | string |          | The channel the file is attached in (for postChannelMessage attachmentIds). |

```json title="listAttachments arguments"
{
  "organizationId": "acme"
}
```

### `startAttachmentUpload`

**Start attachment upload.** Command · no retry key: read before repeating · talks to an outside system

Reserve an attachment on a work item (workItemId), a page (pageId; comment or edit access to its space) or in a channel you are a member of (channelId; then pass its id to [postChannelMessage](/reference/mcp/channels#postchannelmessage)'s attachmentIds) and get a presigned URL. PUT the bytes to `uploadUrl` with `headers` within five minutes, then call [finishAttachmentUpload](/reference/mcp/organization#finishattachmentupload). Allowed types: png, jpg, jpeg, gif, webp, bmp, pdf, txt, md, csv, doc, docx, xls, xlsx, ppt, pptx, zip, mp4, mov, mp3. Files must be between 1 byte and 25 MB.

| Field            | Type    | Required | Description                                                                 |
| ---------------- | ------- | -------- | --------------------------------------------------------------------------- |
| `organizationId` | string  | Yes      | Exact organization id or slug from listOrganizations.                       |
| `workItemId`     | string  |          | The work item the file belongs to.                                          |
| `pageId`         | string  |          | The Lictory Spaces page the file belongs to (instead of workItemId).        |
| `channelId`      | string  |          | The channel the file is attached in (for postChannelMessage attachmentIds). |
| `filename`       | string  | Yes      | File name with its extension, such as diagram.png.                          |
| `mimeType`       | string  | Yes      | The file's media type, such as image/png.                                   |
| `size`           | integer | Yes      | Size in bytes (at most 25 MB).                                              |

```json title="startAttachmentUpload arguments"
{
  "organizationId": "acme",
  "filename": "filename",
  "mimeType": "mimeType",
  "size": 1
}
```

### `removeAttachment`

**Remove attachment.** Command · safe to repeat · destructive

| Field            | Type   | Required | Description                                            |
| ---------------- | ------ | -------- | ------------------------------------------------------ |
| `organizationId` | string | Yes      | Exact organization id or slug from listOrganizations.  |
| `id`             | id     | Yes      | The attachment id (returned by startAttachmentUpload). |

```json title="removeAttachment arguments"
{
  "organizationId": "acme",
  "id": "a5614527-0ce6-43be-ad1d-d012b7394867"
}
```

### `getAttachmentDownloadUrl`

**Get attachment download URL.** Query (read tokens too) · talks to an outside system

A short-lived URL to download an attachment's bytes. The file id appears in `/api/files/<id>` references inside specifications, pages, comments and channel messages. A page's files are available to readers of its space, a channel's to readers of the channel.

| Field    | Type    | Required | Description                                                   |
| -------- | ------- | -------- | ------------------------------------------------------------- |
| `fileId` | string  | Yes      | The file id: the &lt;id> of an /api/files/&lt;id> reference.  |
| `inline` | boolean |          | true: a URL that displays the file instead of downloading it. |

```json title="getAttachmentDownloadUrl arguments"
{
  "fileId": "b914340e-db22-43b0-a8d4-903bc9f20556"
}
```

### `setOrganizationLogo`

**Set organization logo.** Command · safe to repeat

Administrators: upload a PNG, JPEG or WebP logo (at most 512 KB).

| Field            | Type                         | Required | Description                                                                       |
| ---------------- | ---------------------------- | -------- | --------------------------------------------------------------------------------- |
| `organizationId` | string                       | Yes      | Exact organization id or slug from listOrganizations.                             |
| `kind`           | `"mark"`, `"full"`, `"icon"` | Yes      | `mark` is the square logomark; `full` the wide logo; `icon` the browser tab icon. |
| `contentBase64`  | string                       | Yes      | The image bytes, base64-encoded.                                                  |

```json title="setOrganizationLogo arguments"
{
  "organizationId": "acme",
  "kind": "mark",
  "contentBase64": "contentBase64"
}
```

### `removeOrganizationLogo`

**Remove organization logo.** Command · safe to repeat · destructive

Administrators: remove a logo. Without a logomark the initial is shown, without a full logo the name, and without a browser icon the logomark or Lictory's icon.

| Field            | Type                         | Required | Description                                                                       |
| ---------------- | ---------------------------- | -------- | --------------------------------------------------------------------------------- |
| `organizationId` | string                       | Yes      | Exact organization id or slug from listOrganizations.                             |
| `kind`           | `"mark"`, `"full"`, `"icon"` | Yes      | `mark` is the square logomark; `full` the wide logo; `icon` the browser tab icon. |

```json title="removeOrganizationLogo arguments"
{
  "organizationId": "acme",
  "kind": "mark"
}
```

### `setOrganizationBrandColor`

**Set organization brand color.** Command · safe to repeat

Administrators: set the color that tints primary actions and accents for everyone in the organization, and the button and links of its email. Pass null to return to Lictory's colors. The interface adjusts the shade where needed to keep text readable.

| Field            | Type           | Required | Description                                           |
| ---------------- | -------------- | -------- | ----------------------------------------------------- |
| `organizationId` | string         | Yes      | Exact organization id or slug from listOrganizations. |
| `color`          | string or null | Yes      | Six hexadecimal digits, for example #1d4ed8, or null. |

```json title="setOrganizationBrandColor arguments"
{
  "organizationId": "acme",
  "color": "color"
}
```

Call it before telling someone a tool is missing.
