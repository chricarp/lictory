Lictory's MCP server (`POST /api/mcp`, Streamable HTTP) offers 247 tools, generated from the same capabilities the browser uses. A token sees only the tools it may call: read tokens see queries, an agent's token never sees a person's decisions, and an agent limited to some projects never sees an operation that cannot name one of them. [AI agents and MCP](/integrations/agents) explains how to connect.

## Calling tools

A call is a JSON-RPC `tools/call` request with the tool's name and arguments. The result carries the output twice, as the MCP specification asks: as JSON text in `content` for clients that read text, and as `structuredContent`.

```json title="Request"
{
  "jsonrpc": "2.0",
  "id": 7,
  "method": "tools/call",
  "params": {
    "name": "claimItem",
    "arguments": {
      "organizationId": "acme",
      "workItemId": "PAY-142",
      "mutationId": "6f1d2c3b-8a9e-4f70-b1c2-d3e4f5a6b7c8"
    }
  }
}
```

```json title="Result"
{
  "jsonrpc": "2.0",
  "id": 7,
  "result": {
    "content": [
      {
        "type": "text",
        "text": "{\"claimId\":\"0c5e7a52-8f1b-4c3d-9e2a-7b6f5d4c3b2a\",\"workItemId\":\"9d2f4b61-3a7e-4c58-8b19-6e0a2d3c4f5b\",\"key\":\"PAY-142\",\"state\":\"active\",\"status\":\"In progress\",\"leaseExpiresAt\":\"2026-11-26T10:15:00.000Z\"}"
      }
    ],
    "structuredContent": {
      "claimId": "0c5e7a52-8f1b-4c3d-9e2a-7b6f5d4c3b2a",
      "workItemId": "9d2f4b61-3a7e-4c58-8b19-6e0a2d3c4f5b",
      "key": "PAY-142",
      "state": "active",
      "status": "In progress",
      "leaseExpiresAt": "2026-11-26T10:15:00.000Z"
    },
    "isError": false
  }
}
```

- **Identifiers.** `organizationId` takes an organization's id or slug. Wherever a tool takes `workItemId`, a work item key such as `PAY-142` works too.
- **Retries.** Write tools that take a `mutationId` (a UUID you choose) replay their first result when called again with the same value, so nothing is applied twice; the result says `replayed: true`. Write tools without one are marked below as safe to repeat, or say to read the current state first.
- **Unknown fields are refused**, never ignored: a misspelled field or a `mutationId` sent to a tool that takes none is a `validation` error naming the field.
- **Failures are tool results** with `isError: true` and `{ error: { category, message, kind?, issues?, currentRevisionId?, retryable? } }`. Protocol misuse is a JSON-RPC error.

| Category                   | Meaning                                                                                               | What to do                     |
| -------------------------- | ----------------------------------------------------------------------------------------------------- | ------------------------------ |
| `validation`               | The input is wrong (`issues` names the fields)                                                        | Fix the input                  |
| `not_found`, `unavailable` | It does not exist, or you cannot see it                                                               | Rediscover with a list tool    |
| `forbidden`                | Your person, token or agent may not do this (`kind: human_only` when a person must do it, with where) | Tell the person where to do it |
| `conflict`                 | Someone changed it first (`currentRevisionId`), or a `mutationId` was reused for another call         | Read again and reconcile       |
| `external`                 | An outside system failed (`retryable`)                                                                | Retry later when `retryable`   |
