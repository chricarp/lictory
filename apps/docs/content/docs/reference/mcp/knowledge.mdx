What was agreed, where it is written, and the decisions recorded on the way. Every tool takes `organizationId` (an id or slug from `listOrganizations`) unless it says otherwise. See the [overview](/reference/mcp) for errors, retries and what agents may not do.

### `recordDecision`

**Record refinement decision.** Command · retry key `mutationId` · **a person's decision**: refused to agents (the person decides in The work item → Decisions → Record decision)

Record an agreed conclusion with title and body against a specification revision. Optionally cite a resolved specification discussion using sourceThreadId; its original revision is retained. Requires a discipline that edits specifications or reviews. This records a conclusion, never approves a specification or resolves a discussion.

| Field            | Type   | Required | Description                                                                                                                                                                           |
| ---------------- | ------ | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `organizationId` | string | Yes      | Exact organization id or slug from listOrganizations.                                                                                                                                 |
| `mutationId`     | id     |          | Idempotency key. Retrying with the same value never applies the command twice.                                                                                                        |
| `workItemId`     | string | Yes      | Work item id, or its key such as PAY-142 (listWorkItems shows both).                                                                                                                  |
| `baseRevisionId` | string | Yes      | The current revision id you read (getWorkItem). If the item changed since, the call is refused as a conflict with currentRevisionId, so nothing is applied to text you have not seen. |
| `decisionId`     | id     |          | Identifier for the new entity. Omit to have one assigned.                                                                                                                             |
| `title`          | string | Yes      | The decision in one line, such as "Retries reuse the original transaction id".                                                                                                        |
| `body`           | string | Yes      | Context and consequences, in Markdown.                                                                                                                                                |
| `sourceThreadId` | string |          | Discussion the decision came from (from getWorkItem).                                                                                                                                 |

```json title="recordDecision arguments"
{
  "organizationId": "acme",
  "mutationId": "6f1d2c3b-8a9e-4f70-b1c2-d3e4f5a6b7c8",
  "workItemId": "PAY-142",
  "baseRevisionId": "66fdac7b-2ec4-448a-a4d8-61e7fafcd9e5",
  "title": "Retry failed refunds once",
  "body": "Can a refund be retried after settlement?"
}
```

### `setDecisionArchived`

**Archive or restore decision.** Command · retry key `mutationId` · **a person's decision**: refused to agents (the person decides in The work item → Decisions)

Archive or restore a recorded conclusion. Requires edit-specifications in the project, or, for your own decision, a discipline that edits specifications or reviews; authorship alone grants nothing. The original text, revision and history are retained.

| Field            | Type    | Required | Description                                                                    |
| ---------------- | ------- | -------- | ------------------------------------------------------------------------------ |
| `organizationId` | string  | Yes      | Exact organization id or slug from listOrganizations.                          |
| `mutationId`     | id      |          | Idempotency key. Retrying with the same value never applies the command twice. |
| `workItemId`     | string  | Yes      | Work item id, or its key such as PAY-142 (listWorkItems shows both).           |
| `decisionId`     | string  | Yes      | Decision id (from getDecisions or getWorkItem).                                |
| `archived`       | boolean | Yes      | true archives it; false restores it.                                           |

```json title="setDecisionArchived arguments"
{
  "organizationId": "acme",

  "workItemId": "PAY-142",
```

### `getWorkItemKnowledge`

**Get work item knowledge.** Query (read tokens too)

What pages say about a work item, limited to pages you can read: `referencedIn` (pages whose published version mentions the item, with the published `commitId` and the top-level `blockIds`), `citations` (pages the item's specification revisions cite, per revision with pinned `commitIds` and whether the current revision cites them), `attachments` (pages attached with a purpose and optional pinned commit; `attachmentId` for [detachPage](/reference/mcp/spaces#detachpage)), `source` (the committed page content the item was created from, with block and quote), `pageBranches` (page branches proposed from the item, with their pull requests) and `currentRevisionReferences` (items, pages and decisions the current revision references). Read a page with [getPage](/reference/mcp/spaces#getpage).

| Field            | Type   | Required | Description                                                          |
| ---------------- | ------ | -------- | -------------------------------------------------------------------- |
| `organizationId` | string | Yes      | Exact organization id or slug from listOrganizations.                |
| `workItemId`     | string | Yes      | Work item id, or its key such as PAY-142 (listWorkItems shows both). |

```json title="getWorkItemKnowledge arguments"
{
  "organizationId": "acme",
  "workItemId": "PAY-142"
}
```

### `listReferencesTo`

**List references to an item, page or decision.** Query (read tokens too)

Where a work item (`kind: "item"`), a page you can read (`page`) or a recorded decision (`decision`) is referenced: `pages` you can read whose published version mentions it (published `commitId`, `blockIds`, and for pages the pinned versions cited) and `specifications` whose main revisions do (each revision, with the pinned commit for page citations, and whether the item's current revision still does).

| Field            | Type                             | Required | Description                                            |
| ---------------- | -------------------------------- | -------- | ------------------------------------------------------ |
| `organizationId` | string                           | Yes      | Exact organization id or slug from listOrganizations.  |
| `kind`           | `"item"`, `"page"`, `"decision"` | Yes      | What is referenced: a work item, a page or a decision. |
| `id`             | string                           | Yes      | Its id: a work item, page or decision id.              |

```json title="listReferencesTo arguments"
{
  "organizationId": "acme",
  "kind": "item",
  "id": "id"
}
```

### `getDecisions`

**Get recorded decisions.** Query (read tokens too)

Recorded decisions by id (for example the decision references of a page): title, a bounded excerpt of the conclusion, the work item key and title, the revision number it was recorded on, and `archivedAt` (also set when its work item or project is archived: withdrawn from active product knowledge, kept for history). Ids that do not name a decision of this organization are left out. Find decisions with [searchProductKnowledge](/reference/mcp/knowledge#searchproductknowledge).

| Field            | Type           | Required | Description                                           |
| ---------------- | -------------- | -------- | ----------------------------------------------------- |
| `organizationId` | string         | Yes      | Exact organization id or slug from listOrganizations. |
| `decisionIds`    | list of string | Yes      | Decision ids, such as a page's decision references.   |

```json title="getDecisions arguments"
{
  "organizationId": "acme",
  "decisionIds": ["c53c3ae3-a478-4261-ad70-b17707cb761f"]
}
```

### `searchProductKnowledge`

**Find product agreements.** Query (read tokens too)

Search recorded conclusions, approved or delivered specification revisions and published pages of Lictory Spaces in your organization. Results retain the exact version, author and evidence kind: a recorded decision is a conclusion, an approved revision is agreed intent, a delivered revision is recorded delivery scope, and a page is published documentation (`publishing` says whether its space publishes through reviewed pull requests or directly; `commitId` and `version` name the exact version). Published documentation is neither agreed intent nor delivered behavior: prefer agreements and decisions when they disagree, and cite the page version you used. Never infer delivered behavior from approval alone. Archived decisions, archived work items (with the decisions recorded on them), archived projects, archived pages and spaces, live drafts and unmerged page branches are excluded, and pages come only from spaces you can read. Title matches rank first; for equal match quality agreements and decisions rank above reviewed pages, and reviewed pages above directly published ones. Returns bounded excerpts; open the work item or the page ([getPage](/reference/mcp/spaces#getpage) with the commitId) for full evidence.

| Field            | Type                                                        | Required | Description                                                             |
| ---------------- | ----------------------------------------------------------- | -------- | ----------------------------------------------------------------------- |
| `organizationId` | string                                                      | Yes      | Exact organization id or slug from listOrganizations.                   |
| `projectId`      | string                                                      |          | Narrows to this project's work and the spaces homed in it or its teams. |
| `query`          | string                                                      |          | Text to search for.                                                     |
| `limit`          | integer                                                     |          | At most this many results of each kind.                                 |
| `kinds`          | list of `"decision"`, `"approved"`, `"delivered"`, `"page"` |          | Only these evidence kinds (default: all).                               |

```json title="searchProductKnowledge arguments"
{
  "organizationId": "acme"
}
```

### `searchKnowledge`

**Search pages and work.** Query (read tokens too)

Full-text search across what you can read: published pages of Lictory Spaces (the published version on main, never live drafts or branches), work items (title and current specification), recorded decisions and approved or delivered specification revisions. Each result names its kind (page, item, decision, approved, delivered), the exact version (page commitId and version number, or revision number), a link, an excerpt around the match with highlight offsets and whether the title or only the content matched. Results are for finding things: a textual match is not evidence of authority (use [searchProductKnowledge](/reference/mcp/knowledge#searchproductknowledge) for agreements). Case-insensitive phrase match; title matches first, then most recent; at most `limit` results of each kind. Decisions and approved or delivered revisions link to that exact revision (`href`) and to the item as it is now (`currentHref`). `more` lists the kinds with results after this batch: ask again with the returned `cursor` and those kinds for the next one (results added meanwhile are not repeated).

| Field            | Type                                                                  | Required | Description                                                                              |
| ---------------- | --------------------------------------------------------------------- | -------- | ---------------------------------------------------------------------------------------- |
| `organizationId` | string                                                                | Yes      | Exact organization id or slug from listOrganizations.                                    |
| `query`          | string                                                                | Yes      | Text to search for.                                                                      |
| `projectId`      | string                                                                |          | Narrows to this project's work and the spaces homed in it or its teams.                  |
| `kinds`          | list of `"page"`, `"item"`, `"decision"`, `"approved"`, `"delivered"` |          | Only results of these kinds; omitted: every kind.                                        |
| `limit`          | integer                                                               |          | Most results to return.                                                                  |
| `cursor`         | string                                                                |          | The `cursor` of the previous batch, to continue after it (with the kinds in its `more`). |

```json title="searchKnowledge arguments"
{
  "organizationId": "acme",
  "query": "refund"
}
```
