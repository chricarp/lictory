---
title: Keyboard shortcuts
description: Every keyboard shortcut in Lictory, by where you use it.
---

Lictory can be used with the keyboard throughout. The tables below list
every shortcut there is. `Mod` is `⌘` on a Mac and `Ctrl` elsewhere.

Single-letter shortcuts (`C`, `/`, `J`, `K`, `O`) do nothing while you type
in a field or an editor, so they never interfere with writing.

## Anywhere

| Keys    | Does                                                          |
| ------- | ------------------------------------------------------------- |
| `Mod K` | Open or close the command palette                             |
| `/`     | Open the command palette                                      |
| `C`     | Create a work item in the current project                     |
| `Mod J` | Open or minimize Litto, with any text you selected as context |
| `Esc`   | Close the open dialog, palette, preview, picker or card       |

In the command palette, `↑` and `↓` choose a result, `Enter` opens it and
`Esc` closes the palette. In the create dialog, `Enter` is **Create & open**.

## Lists

In **All items**, saved views and the list beside an open item:

| Keys           | Does                      |
| -------------- | ------------------------- |
| `J` or `↓`     | Move to the next item     |
| `K` or `↑`     | Move to the previous item |
| `Enter` or `O` | Open the highlighted item |

On the board and the backlog, `Esc` closes the item preview.

## Writing

In every editor: specifications, branch drafts, descriptions, discussions,
decisions and pages.

| Keys                      | Does                                                     |
| ------------------------- | -------------------------------------------------------- |
| `Mod B`                   | Bold                                                     |
| `Mod I`                   | Italic                                                   |
| `Mod Shift S`             | Strikethrough                                            |
| `Mod E`                   | Inline code                                              |
| `Mod Alt 1` … `Mod Alt 6` | Heading 1 to 6                                           |
| `Mod Shift 8`             | Bulleted list                                            |
| `Mod Shift 7`             | Numbered list                                            |
| `Mod Shift 9`             | Task list                                                |
| `Mod Shift B`             | Quote                                                    |
| `Mod Alt C`               | Code block                                               |
| `Shift Enter`             | Line break inside a paragraph                            |
| `Mod Z` / `Mod Shift Z`   | Undo / redo (in live editors, only your own changes)     |
| `Mod Enter`               | Save or post: **Save revision**, post a comment or reply |
| `Esc`                     | Cancel, where the field has a **Cancel**                 |

Markdown you type is formatted as you go: `# ` starts a heading, `- ` a
list, `1. ` a numbered list, `> ` a quote, `[ ] ` a task, three backticks and a
space a code block. **Edit as Markdown** in the toolbar switches to the plain text.

The formatting toolbar is one stop in the tab order: `←` and `→` move
between its controls, `Home` and `End` jump to the first and last.

### Pickers

Type `/` for blocks (headings, lists, tables, a decision…), `#` for a work
item, `[[` for a page and `@` for a person. While a picker is open:

| Keys             | Does                                                     |
| ---------------- | -------------------------------------------------------- |
| `↑` `↓`          | Choose an option                                         |
| `Enter` or `Tab` | Insert it                                                |
| `Shift Enter`    | Insert its alternative: for a page, **Pin this version** |
| `Esc`            | Close the picker and keep typing                         |

### Discussions

| Keys                   | Does                                                                                                                                                                |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Mod Alt M`            | Comment on the selected text of a specification you are reading, or of a page in its editor. In a specification with nothing selected, open the discussion composer |
| `Alt ↓` / `Alt ↑`      | In a specification's discussion panel, move to the next or previous discussion and mark its passage                                                                 |
| `Alt Home` / `Alt End` | Jump to the first or last discussion                                                                                                                                |
| `Mod Enter`            | Post the comment or reply                                                                                                                                           |

### Pages

| Keys           | Does                                                                                    |
| -------------- | --------------------------------------------------------------------------------------- |
| `Enter` or `↓` | In a page's title, move into the content                                                |
| `Mod Enter`    | In the message of **Publish this page** or **Commit to this branch**, publish or commit |

In a space's page tree: `↑` `↓` move between pages, `→` expands and `←`
collapses (or goes to the parent), `Home` and `End` jump to the first and
last page, `Enter` opens it, `Alt ↑` / `Alt ↓` move a page among its
siblings, and `Shift F10` (or the context menu key) opens its actions.

## Ordering and panes

| Keys                                  | Does                                                                           |
| ------------------------------------- | ------------------------------------------------------------------------------ |
| `Alt ↑` / `Alt ↓`                     | On an Epic's stories, move the focused story up or down                        |
| `←` `→` on a focused pane edge        | Resize the work item list, the review rail or Litto (`Shift` for larger steps) |
| `Home` / `End` on a focused pane edge | Smallest or largest size                                                       |
| `Esc` while dragging a pane edge      | Put it back where it was                                                       |

## Litto

| Keys              | Does                                                      |
| ----------------- | --------------------------------------------------------- |
| `Enter`           | Send the message                                          |
| `Shift Enter`     | New line                                                  |
| `Mod Shift Space` | Start or stop dictation, where dictation is available     |
| `Esc`             | Stop dictation without keeping it; otherwise close Litto  |
| `Mod Shift O`     | Start a new conversation (on the Litto page)              |
| `A`, `B`, `C`…    | When Litto asks a question with options, choose an option |
| `Enter`           | In Litto's questions, go to the next question             |

## What has no shortcut

Moving cards on the board and ranking the backlog are done with the pointer.
From the keyboard, change an item's status, sprint or cycle in its
properties instead. Selecting text in a published page or a specification
you are reading needs a pointer (or your browser's caret browsing); then
`Mod Alt M` comments on it.
