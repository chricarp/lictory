# Lictory identity

The mark consists of two nested review brackets forming an L. The independent
forms represent different perspectives aligning around an agreed specification.
Open space separates the forms; rounded turns soften the geometric structure.

Use the mark in one color with strong contrast. The application inherits its
foreground color so the identity works in both light and dark themes. Pair it
with the lowercase name in the application's Geist typeface. Keep at least one
stroke width of clear space around the visible mark. Avoid gradients, shadows
inside the mark, rotation, or stretching.

The standalone SVG uses a 32-unit grid and six-unit strokes expressed as filled
paths. The browser icon places the same geometry on an ink (`#171C19`) tile with
a warm white (`#FAF9F6`) glyph. The Apple touch icon is a 180px raster export of
that SVG. Regenerate it when changing the icon geometry.

## Inspiration

The direction was developed using [Logosystem's moodboard builder](https://logosystem.co/moodboard).
Selected references informed visual principles, not the final geometry:

- [Gurucul, credited to Jared Granger by Logosystem](https://x.com/aessestudio/status/1842463658296606881): modular construction and strong silhouette.
- [Manifold by Fabian Arbor](https://x.com/fabianarbor/status/1782809910125957300): connected perspectives and approachable curves.
- [Clyc by Derek Sieber](https://twitter.com/DerekSieber/status/1700627413388963966/photo/1): consistent weight and softened geometric corners.

Reference artwork belongs to its respective designers and is not shipped with
the application. Lictory's mark is newly drawn vector geometry.
